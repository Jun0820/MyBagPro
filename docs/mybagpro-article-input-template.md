# MyBagPro 記事入力テンプレート

MyBagPro の記事制作プロンプトの下に貼って使う入力テンプレートです。

## 今回の記事情報

```text

{ここに記事テーマ}

{プロフィール記事 / クラブセッティング記事 / 悩み解決記事 / 比較記事 / ランキング記事 / 更新通知記事 / ニュース解説記事 / メーカー別まとめ記事 / 選手タイプ別記事}

{狙うキーワード}

{関連キーワード}

{誰向けか}

{検索流入 / 詳細ページ誘導 / AI診断誘導 / 比較ページ誘導 / 購入導線}

{プロフィール、クラブ情報、選手情報、比較対象、悩み、商品情報など}
```

## 記事タイプが未定の場合

記事タイプがまだ決まっていない場合は、次の指示を追加します。

```text
記事タイプが明確でない場合は、入力データと記事テーマを見て、以下から最適な記事タイプを1つ選んでください。

・プロフィール記事
・クラブセッティング記事
・悩み解決記事
・比較記事
・ランキング記事
・更新通知記事
・ニュース解説記事
・メーカー別まとめ記事
・選手タイプ別記事

そのうえで、選んだ理由を簡単に説明し、最適な構成で記事を作成してください。
```

## MyBagProで最初に強化すべき記事順

1. プロフィール記事

まず入口を増やす。
「選手名 プロフィール」で拾って、クラブセッティング詳細に流す。

2. クラブセッティング記事

MyBagProの本命。
「選手名 クラブセッティング」「選手名 使用クラブ」で狙う。

3. 悩み解決記事

AI診断に一番つなげやすい。
「5番アイアン 苦手」「ドライバー 吹け上がる」「ウェッジ 何本」など。

4. 比較・ランキング記事

内部回遊と購入導線を強化する。
「女子プロ ドライバー」「PING 使用プロ」「プロ パター ランキング」など。

## 使い分けの結論

| 記事タイプ | 役割 |
|---|---|
| プロフィール記事 | 選手名検索の入口 |
| クラブセッティング記事 | MyBagProの本命記事 |
| 悩み解決記事 | AI診断・購入導線に強い |
| 比較記事 | 内部回遊と検討を深める |
| ランキング記事 | 検索流入とSNS向き |
| 更新通知記事 | 新規データ公開・更新告知 |
| ニュース解説記事 | 話題性から流入を取る |
| メーカー別まとめ記事 | メーカー名・クラブ名検索を取る |
| 選手タイプ別記事 | 自分に近いプロを探す導線 |
